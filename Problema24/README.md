# Problema 24 - ¿Día hábil?

**Estructura elegida:** Switch

**Justificación:** Se utiliza `switch` con casos múltiples para agrupar los días de la semana y asignar correctamente si es día hábil o fin de semana, manejando valores inválidos en el `default`.
